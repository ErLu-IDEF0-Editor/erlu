# erlu

**محرر للنماذج الوظيفية وفق IDEF0 لسطح المكتب والمتصفح، مطوّر بلغة Rust وبواجهة egui.**

يساعد erlu على وصف وظائف النظام ومدخلاتها وضوابطها ومخرجاتها وآلياتها. ابدأ بمخطط السياق، ثم أضف التفاصيل عن طريق تفكيك الوظائف إلى مستويات أدق.

يستهدف البرنامج المحللين والمهندسين والمعماريين الذين يستخدمون IDEF0 لفهم العمليات وتصميمها. ويمكن للمطورين توسيعه بإضافات WASM وربطه بأدوات خارجية ووكلاء ذكاء اصطناعي.

## الإمكانات

- **نمذجة IDEF0:** كتل وظيفية وأسهم متعامدة وتفرعات وتفكيك هرمي وواجهات موروثة وأنفاق ومراجع إلى الوظائف.
- **سجل موحّد للمستند:** التراجع والإعادة عبر المخططات، بما يشمل تعديلات الواجهة والذكاء الاصطناعي والإضافات.
- **التحقق من النموذج:** تشخيص البنية والروابط والترقيم والقواعد الدلالية لـ IDEF0.
- **تحليل التكاليف:** تحديد تكلفة الوظائف وحساب المجاميع عبر مستويات التفكيك.
- **التصدير:** PDF وSVG وMarkdown.
- **المظهر:** سمات فاتحة وداكنة وألوان للعناصر، وواجهة بالإنجليزية والروسية والفرنسية والإسبانية والعربية والصينية المبسطة.
- **الأتمتة:** MCP على سطح المكتب وموصل لوكيل خارجي في المتصفح.

تساعد الفحوص المدمجة على اكتشاف أخطاء النمذجة، لكنها لا تمثل شهادة شاملة بالمطابقة للمعيار. راجع [نطاق التحقق](docs/validation.md).

## سطح المكتب والويب

يستهدف تطبيق سطح المكتب Linux وWindows وmacOS. وتشترك نسخة المتصفح معه في محرك النموذج والسجل والتحقق والتصدير.

تُعالج المستندات محليًا. لا يتطلب التحرير في المتصفح حسابًا أو خادم قاعدة بيانات للمستندات. تُفتح الملفات من نافذة اختيار الملفات وتُحفظ بتنزيلها. تتوفر نسخة للاستعادة في IndexedDB والعمل دون اتصال بعد تثبيت ذاكرة التطبيق المؤقتة. الاستعادة لا تغني عن حفظ الملفات.

اختُبر Linux/NixOS ومتصفحات Chromium وFirefox وWebKit محليًا. يوضح [سجل القبول](docs/acceptance.md) حالة المنصات ومحركات المتصفح الأخرى.

## الإضافات

يتضمن البرنامج ثلاث إضافات WASM:

| الإضافة | الغرض |
| --- | --- |
| Colors | ضبط ألوان الكتل والأسهم المحددة |
| [Responsibility Map](plugins/responsibility_map/README.md) | الأدوار التنظيمية وتوزيع المسؤوليات والفحوص وتصدير مصفوفة RACI |
| [Semantic Dictionary](plugins/semantic_dictionary/README.md) | المفاهيم والمرادفات وربطها بالأسهم والبحث عن الاستخدامات واتساق التسميات |

يعمل مكوّن WASM نفسه عبر Wasmtime على سطح المكتب وعبر Worker في المتصفح. تستطيع الإضافات تقديم أوامر وفحوص ومصدّرات ونماذج إدخال.

تمر تعديلات الإضافات عبر محرك المعاملات المشترك وتدعم التراجع والإعادة. لا تتيح النسخة الأولى من SDK تسجيل لغات نمذجة جديدة أو عناصر واجهة مخصصة اعتباطية.

## التشغيل من المصدر

### Nix / NixOS

من جذر المستودع:

```sh
nix-shell
npm --prefix web ci
npm --prefix web run plugins
```

الأوامر التالية، بالترتيب، لتشغيل تطبيق سطح المكتب أو فتح النموذج التجريبي أو تشغيل الويب على `http://127.0.0.1:8080`:

```sh
cargo run -p erlu
```

```sh
cargo run -p erlu -- examples/order-fulfilment.idef0
```

```sh
trunk serve
```

توفر بيئة Nix أدوات البناء ومكتبات التشغيل. لا حاجة إلى تثبيت Trunk مجددًا عبر Cargo. ويمنع مجلد بناء خاص بكل مترجم اختلاط ملفات Nix وrustup.

### دون Nix

تحتاج إلى Rust وNode.js 22+ وPython 3 وTrunk وwasm-tools. إصدار Rust محدد في `rust-toolchain.toml`.

```sh
rustup target add wasm32-unknown-unknown
cargo install wasm-tools --version 1.263.0 --locked
cargo install trunk --version 0.21.14 --locked
npm --prefix web ci
npm --prefix web run plugins
```

استخدم بعدها أوامر التشغيل السابقة. يحتاج Linux أيضًا إلى مكتبات X11/Wayland وlibxkbcommon وOpenGL.

## الذكاء الاصطناعي والأتمتة

اربط عميل MCP بعملية مستقلة للمحرر، أو تحكم في مستند نافذة سطح مكتب مفتوحة:

```sh
cargo run -p erlu -- mcp --headless
```

```sh
cargo run -p erlu -- --mcp
```

تتوفر معلومات الاتصال في قائمة **AI**. تستخدم تعديلات MCP السجل والفحوص نفسها المستخدمة في الواجهة. ويجب تنفيذ الحفظ على القرص صراحةً.

في المتصفح، تتصل الوكلاء عبر [SDK بلغة JavaScript/TypeScript](web/sdk/erlu-agent.js). يمنح المستخدم الوصول لأصل ويب محدد ويمكنه سحبه. يوفر التكامل محوّل الوكيل؛ ولا يلزم وجود محادثة ذكاء اصطناعي مدمجة. راجع [واجهة الذكاء الاصطناعي](docs/ai.md).

## للمطورين

| الحزمة | المسؤولية |
| --- | --- |
| `erlu-core` | النموذج والأوامر والمعاملات والسجل والتحقق والهندسة والتصدير |
| `erlu-app` | واجهة egui ومحوّلات سطح المكتب والويب وMCP |
| `erlu-plugins` | تحميل مكوّنات WASM وتشغيلها على سطح المكتب |

تشترك الواجهة وMCP وموصل المتصفح والإضافات في سجل إجراءات واحد. تكشف فحوص رقم المراجعة التعارضات أثناء التحرير غير المتزامن.

تُحفظ المستندات بتنسيق JSON ذي الامتداد `.idef0` مع إصدار مستقل وقائمة صريحة بالقدرات. يتيح سجل الترحيلات والاحتفاظ بالبيانات الاختيارية غير المعروفة التوافق مستقبلًا. لا تُدعم مستندات Qt القديمة أو إضافاته الثنائية.

يمكن إنشاء مستندات DFD مستقلة بامتداد `.dfd` من قائمة «ملف». راجع [دليل DFD](docs/dfd.md).

### الفحص والبناء

```sh
cargo test --workspace --locked
cargo build -p erlu --release --locked
trunk build --release --locked
npm --prefix web test
```

توجد نسخة الويب الثابتة في `dist/web` ويمكن استضافتها عبر HTTPS. ينشئ [سير عمل الإصدار](.github/workflows/release.yml) أرشيفات سطح المكتب وملف ZIP للويب ومجاميع تحقق. وهو مخصص لـ GitHub Actions؛ ويتطلب Forgejo تكييف CI. لم يُشغّل سير عمل الإصدار عن بُعد بعد.
