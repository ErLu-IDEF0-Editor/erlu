- Исходный Qt-проект собран через `nix-shell`, запущен на Xvfb; сохранены
  [сценарии и снимки исходного UX](ux/baseline.md).
- Rust desktop собран и запущен с OpenGL на Xvfb; сохранён
  [снимок новой версии](ux/erlu-rust-example.png).
- `nix-build --no-out-link`: пакет с поставляемым компонентом цветов собран,
  встроенные 15 тестов ядра прошли. MCP проверен также из установленного Nix-пакета.
- `cargo test --workspace --locked`: 19 тестов — модель/история/совместимость,
  PDF, WASM-плагины и HTTP MCP. Проверяются откат транзакции, конфликты ревизий,
  наследование интерфейсов, туннели, ветвление, сохранение неизвестных полей,
  стабильность ID, восстановление документа и остановка зависшего компонента.
- `cargo clippy --workspace --all-targets --locked -- -D warnings` и rustfmt.
- Реальный stdio MCP: initialize, 41 инструмент с поставляемым плагином,
  редактирование, конфликт ревизии, запуск компонента цветов, undo.
- HTTP MCP: отказ без токена, отказ постороннему Origin, успешный initialize.
- Общий компонент цветов собран и выполнен через Wasmtime и браузерный Worker.
- `trunk build --release --locked`: статическая web-сборка, без backend.
- Chromium / Playwright: 7 из 7 сценариев проходят — редактирование, декомпозиция,
  глобальная история, PDF, плагин, конфликты ревизий, неизвестные поля формата,
  создание блоков и стрелок мышью, соединение унаследованных интерфейсов,
  Ctrl+Up, выдача/отзыв AI-доступа и офлайн-перезагрузка.
- Векторный PDF из [примерной модели](../examples/order-fulfilment.idef0):
  обе страницы A4 отрисованы Poppler и визуально проверены. Отдельно проверены
  кириллица и французские символы. Регрессия масштаба PDF покрыта тестом.
- JSON Schema документа и реестр действий сгенерированы из Rust CLI
  в `docs/schema/`; JavaScript SDK проходит синтаксическую проверку.

- `cargo build -p erlu --locked -j3` — успешно, включая готовый desktop-бинарник.

- Desktop-бинарник запущен внутри `nix-shell` на Xvfb. Открылось окно с

- `trunk serve --release --locked` запущен внутри `nix-shell`; Chromium проверял

## Границы проверки

Интерактивная проверка Windows и macOS в этой Linux-среде не выполнялась.
Firefox и WebKit проверены локально вместе с Chromium; см. запись CI ниже.
Подготовлены упаковщики; AppImage и системные ассоциации файлов ещё требуют
отдельной проверки. CI настроен для Linux,
Windows, macOS ARM64/x86_64 и Playwright Chromium/Firefox/WebKit. Удалённый CI
не запускался и артефакты не публиковались. Подпись установщиков не настроена.

Перед объявлением полной UX-приёмки нужно пройти таблицу из `ux/baseline.md`
на каждой ОС: системные файловые диалоги, несколько окон, ассоциации файлов,
горячие клавиши на разных раскладках, touchpad/pinch, печатные размеры и темы.
Автоматизированные браузерные сценарии покрывают основные операции, но не
заменяют эту ручную приёмку. Для сравнения сохранены сценарии и снимки UX;
исходники Qt доступны в истории Git, ревизия `58198c6`.

Новый формат v1.0 намеренно не читает старый Qt JSON. Реестр миграций готов
для последующих версий, но в первой версии нет выдуманной миграции v0→v1.
Браузерный AI-коннектор требует разрешения вкладки и адаптера внешнего агента;
встроенный чат и удалённый MCP relay в эту реализацию не входят.

### Меню и подключение внешних плагинов

Плагины с более чем тремя видимыми действиями получают подменю; скрытые действия
подтверждения не учитываются. Необязательный `title` задаёт имя подменю, старые
манифесты без него используют `id`. Встроенные названия и пункт «Подключить внешний
плагин…» переведены на шесть языков. Desktop выбирает внешний `plugin.json`, web
принимает URL на origin приложения. Пересборка erlu для готового пакета не нужна.

Проверена отдельная копия исходников только с этой правкой: web release-сборка,
`cargo check -p erlu`, Rust-тесты ядра и хоста плагинов, форматирование и синтаксис
JavaScript. Новые браузерные сценарии под `/erlu/` прошли **10/10** проверок
в Chromium и Firefox без retries: граница 3/4 видимых действий, исключение скрытых
подтверждений, манифесты с `title` и без него, выполнение WASM-действия через форму,
а также встроенные подменю на русском при ширине окна 1280 и 570 пикселей.
Внутри подменю повторяющееся название плагина убрано из переведённых подписей.
