# Semantic Dictionary

WASM-плагин erlu для словаря понятий, синонимов и согласованности подписей стрелок.
Входит в desktop и web; команды доступны в меню **Plugins**, через MCP и web API.

## Основной сценарий

1. **Add concept…**: задайте уникальный код, основной термин, определение,
   владельца и источник. Код неизменяемый и различает омонимы: `customer_request`
   и `supplier_request` могут иметь одинаковое название «Заявка».
2. **Add synonym…**: добавьте варианты написания. **Edit concept field…** изменяет
   ровно одно поле; переименование термина не изменяет подписи диаграмм.
3. Выделите стрелки и выполните **Bind selected arrows…** по коду понятия.
   Привязывается вся группа наследуемой подписи, включая связанные ветви и
   интерфейсы декомпозиции. Подписи сохраняются. Для замены другого понятия
   включите **Replace existing concept bindings**.
4. **Find concept uses…** показывает стрелки, диаграммы и роли ICOM.
   **Search dictionary…** ищет по коду, термину, синонимам, определению,
   владельцу и источнику.
5. **Preview label normalization…** показывает старые и новые подписи и все
   затрагиваемые стрелки, включая находящиеся вне выделения. Только кнопка
   **Apply previewed changes** применяет изменение одной транзакцией.
6. **Export dictionary…** формирует Markdown, CSV или переносимый JSON-каталог.
   Отчёт можно скопировать и сохранить; web скачивает файл.

Область отчётов: вся модель, активная диаграмма или выделение. Экспорт всей модели
включает неиспользованные понятия; для диаграммы/выделения экспортируются только
понятия, связанные с её стрелками. Ссылки на источник хранятся как текст; сеть
для получения источников не используется.

## Значение связей

Связи используют стабильные ID стрелок и понятий. При привязке сохраняются записи
для всех существующих стрелок группы. Новая ветвь или дочерний интерфейс получает
эффективную связь через источник подписи. Независимо подписанные ветви являются
отдельными группами. Стрелки вызова и незавершённые интерфейсные заглушки исключены.
Привязка разных понятий внутри одной группы диагностируется и блокирует унификацию.

**Unbind selected arrows** снимает связи со всей выбранной группы. Понятие можно
удалить только после снятия привязок. **Prune deleted arrows** удаляет записи
удалённых/неподдерживаемых стрелок и оставляет живые связи. Изменения поддерживают
Undo/Redo и сохраняются в `.idef0`; без плагина данные расширения сохраняются.

## Политика диагностики

Это дополнительные проверки словаря, не требования ISO-валидации IDEF0.
`source` диагностик — `semantic_dictionary`.

- Ошибки: `conflicting_bindings`, `unknown_concept`.
- Предупреждения: `missing_definition`, `ambiguous_spelling`, `ambiguous_label`,
  `unbound_label`, `noncanonical_label`, `binding_label_mismatch`, `orphan_binding`.

При сравнении написаний используются нижний Unicode-регистр, удаление внешних
пробелов и схлопывание пробельных последовательностей. Морфология, нечёткий поиск
и смысловая близость не вычисляются. Автоматическое связывание по написанию
отсутствует: омонимы и пересекающиеся синонимы всегда требуют явного выбора кода.
Проверка пересечений написаний охватывает весь словарь даже при узкой области.

## Импорт и предпросмотры

**Preview JSON catalog import…** принимает объект JSON:

```json
{"version":1,"concepts":[{"code":"customer_request","term":"Заявка клиента","definition":"Запрос клиента на услугу","aliases":["Заявка"],"owner":"Операционный отдел","source":"Регламент обработки заявок"}]}
```

Новые коды добавляются, идентичные записи пропускаются. Различающиеся записи с
существующим кодом блокируют весь импорт; перезаписи и частичного применения нет.
Омонимы разрешаются и перечисляются в предупреждениях. Внешние ID и привязки
игнорируются: каталог переносит только понятия. После предпросмотра нажмите
**Apply previewed changes**.

Предпросмотры фиксируют ревизию документа. Любое редактирование, Undo/Redo или
открытие другого документа делает старое применение недействительным. Смена
выделения и навигация не меняют состав уже просмотренной унификации: её аргументы
фиксируют конкретные группы стрелок. После конфликта сформируйте новый предпросмотр.

## API

Префикс команд: `plugin_semantic_dictionary_`; точки в названиях ниже заменяются
подчёркиваниями. Аргумент `scope` принимает `document` (по умолчанию), `diagram`
или `selection`.

| Действие | Аргументы |
| --- | --- |
| `concept.add` | `code`, `term`; необязательные `definition`, `owner`, `source` |
| `concept.update` | `code`, `field: term/definition/owner/source`, `value` |
| `concept.remove` | `code` |
| `alias.add`, `alias.remove` | `code`, `alias` |
| `binding.set` | `code`, необязательный `replace: false`; использует выделение |
| `binding.clear` | Использует выделение |
| `search` | `query`, `scope` |
| `usage` | `code`, `scope` |
| `validate` | `scope` |
| `normalize.preview` | `scope`, необязательный `code` для фильтра |
| `normalize.apply` | `roots`, `preview_revision` из предпросмотра |
| `catalog.export` | `scope`, `format: markdown/csv/json` |
| `catalog.import_preview` | `catalog` |
| `catalog.import_apply` | `catalog`, `preview_revision` из предпросмотра |
| `data.prune` | — |

Предпросмотр возвращает `result.confirm_action` с `name`, `arguments`,
`expected_revision`. MCP/web-клиент передаёт их в отдельный вызов после просмотра
результата. Apply-команды скрыты из обычного GUI-меню, но доступны в API.
Экспорт возвращает `text`, `filename`, `mime`, `concept_count`.

Данные версии 1 находятся в `extensions.semantic_dictionary`: `next_id`,
`concepts` и `bindings`. Неизвестная версия отклоняется без перезаписи; неизвестные
поля текущей версии сохраняются при изменениях. Данные являются дополнительными
аннотациями и не вводят обязательную capability. Ограничения: 1000 понятий,
1000 переименовываемых групп за транзакцию и 3 МиБ ответа; при превышении сужайте
область. CSV экранирует кавычки/переносы и обезвреживает формульные префиксы;
Markdown экранирует ячейки.

## Сборка

```sh
npm --prefix web run plugins
cargo test --manifest-path plugins/semantic_dictionary/Cargo.toml --locked
node --test web/test-plugin-confirmation.mjs
cargo test --workspace --locked
trunk build --release --locked
```
